## 四、诚实边界

1. **公平摇号上界**: 排列5每位独立均匀分布，Top-1 理论值=10%，Top-5 理论值=50%。任何"超随机"声称须满足 95%CI 下界 > 随机且跨 ≥3 窗口稳健。
2. **六环一致结论**: P0/P1/P2/P3 所有参数档位的 Top-5 95%CI 下界均 ≤ 50% → 无稳健超随机杠杆。
3. **监控层价值**: 虽然无法超越随机，但监控层提供了持续的数据质量保证、漂移告警和退化回滚能力——这是系统长期稳健运行的务实资产。
4. **特征展示原则**: GUI 展示的频率/遗漏值均为历史真实统计，`relative_hotness` 为相对热度（非命中概率），confidence 字段已降级。
