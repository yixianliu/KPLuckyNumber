## 2. Wilson 95% 置信区间（单一实现）

- **唯一实现**：`modules/stats_utils.py::wilson_ci(successes, total, z=1.96)`
  返回 `(lower, upper)` 二元组，均已钳制到 `[0, 1]`；`total == 0` 返回
  `(0.0, 0.0)`；`successes` 越界 `[0, total]` 时按比例钳制（防御
  `math domain error`）。
- **钳制边界现实**：`min(1.0, ·)` / `max(0.0, ·)` 捕获的是**上溢/下溢越界**；
  p=1（全命中）时上界数学值恰为 1，但 center/half 分离两次除法存在
  <= 1ulp 浮点下溢（实测 0.9999999999999999 @ z=1.96），不强行抹平
  （抹平需重构算术分组，将引入全量 ~1ulp 漂移，违背零漂移原则）。
  单测以 `delta=1e-12` 容差断言（偏差 4，见 §5）。
- **口径换算（百分数场景）**：GUI / 可视化/报告层的百分数口径换算方式为
  `wilson_ci(v * N / 100.0, N)[i] * 100.0`（v 为百分数、N 为代表性窗口数），
  与收敛前内嵌百分数实现存在 ~1ulp 浮点差异，绘图层无感。
- **报告义务**：任何「命中率提升」说法必须同时给出点估计与 Wilson 95% CI；
  CI 下界与随机基线重叠即视为**无统计显著超额**。
- **偏差登记**：方案 ALG-06 文本签名为三元组 `Tuple[float, float, float]`，
  现状全仓调用点均按二元组解包，按零漂移原则保持二元组（偏差 1，见 §4）。

## 3. Top-1 真实口径 / Top-3 覆盖口径（双口径分离）

定义源码锚点：`modules/online_learner.py::_calculate_hits`（L351）：

| 口径 | 字段 | 语义 | 定位 |
| ---- | ---- | ---- | ---- |
| Top-1 真实口径 | `top1_hits` | 每位置**最高概率号（首推号）**与实际号精确相等，5 位累加（0-5） | 反映真实预测力，评估主口径 |
| Top-3 覆盖口径 | `partial_hits` | 实际号落入该位置推荐概率**前 3** 集合，5 位累加（0-5） | 宽松参考，保留旧语义 |
| 组合完全命中 | `exact_match` | 推荐组合（Top-5 内）与实际 5 位全等 | 极稀缺（~10^-5 量级），仅作展示 |
| 推荐质量评级 | `recommendation_quality` | `exact_match>0`→excellent；`top1_hits>=4`→good；`>=3`→fair；否则 poor | **按 Top-1 口径评级**，避免被覆盖口径虚高污染 |

不变量：`partial_hits >= top1_hits`（覆盖口径是真实口径的超集）。

## 4. overall_score 公式（只读登记，禁止擅改）

源码锚点：`modules/backtester.py`：

- `_evaluate_prediction`（L485）实际计算：`overall_score = round((top1_hits * 40 + top3_hits * 20) / 3, 2)`（L568）
- 同方法 docstring（L498）写 `/ 5`，为**过期文档**（/3 时理论满分恰为 100，与
  docstring「满分 100」自洽）；docstring 与代码不一致，**本次仅登记不修复**。
- `_calculate_overall_stats`（L598）按记录 `overall_score` 求均值。

权重语义：Top-1 命中权重 40 >> Top-3 权重 20，强调「精准命中头号推荐」更重要。
任何调整必须先在本文档登记并经评审，不允许代码先行。

## 5. 偏差登记表

| # | 偏差 | 原因 | 影响 |
| - | ---- | ---- | ---- |
| 1 | wilson_ci 保持二元组返回，方案文本为三元组 | 全仓调用点按二元组解包，三元组化必致 unpack 报错；零漂移优先 | 无（无调用点使用第三返回值） |
| 2 | 百分数换算 ~1ulp 浮点差异 | 计数口径换算往返 | 绘图层无感；数值结论不变 |
| 3 | backtest_multisource 版 n==0 原返回整型 (0, 0) | 单一实现统一为 (0.0, 0.0) | 调用点仅解包/格式化，无行为差异 |
| 4 | p=1 时上界非精确 1.0（低 <=1ulp） | center/half 分离两次除法浮点下溢 | 数值结论不变；单测 delta=1e-12 容差断言 |
