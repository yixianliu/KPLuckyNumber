--------------------------------------------------------------
一、目标用户
--------------------------------------------------------------
1. 彩票数据研究者
   需要系统化采集、结构化存储历史开奖数据，替代手工 Excel 整理。
2. 量化/算法爱好者
   想在一个完整项目里对比多算法融合效果，而非零散拼凑脚本。
3. Python 学习者
   寻找一个可运行、有真实业务场景的桌面 GUI 项目，作为学习参考。
4. 数据分析工程师
   需要"数据采集 → 预测 → 回测 → 验证 → 在线学习"完整闭环的代码模板。

--------------------------------------------------------------
二、核心痛点
--------------------------------------------------------------
痛点 1：数据源分散，手工整理低效
  开奖数据散落在多个网站，手动复制粘贴不仅耗时，还容易出错。
  解决：内置多源爬虫，增量/全量一键获取，数据自动入 MySQL。

痛点 2：单算法脚本满天飞，无法系统对比
  网上能找到大量单算法预测代码，但没有统一融合框架，更缺乏
  "同一输入、可复现对比"的环境。
  解决：七算法 + ml_supervised 混合融合，权重透明可查。

痛点 3：预测完不知道对错
  很多项目只负责预测，没有闭环验证。
  解决：内置在线学习 + 滚动回测 + 命中率统计，每期开奖后自动验证并记录。

痛点 4：AI 输出不可控，黑箱难解释
  大模型返回乱格式 JSON，无法落库，也无法解释"为什么选这组号码"。
  解决：JSON 修复 + 逐算法归因列，每期预测都有完整推理链可追溯。

痛点 5：复杂项目跑不起来
  依赖多、环境杂、数据库没连上直接崩，是最常见的劝退原因。
  解决：惰性加载（Lazy Import），缺少 Redis/matplotlib 也能启动主界面，
        降级路径清晰。

--------------------------------------------------------------
三、解决方案
--------------------------------------------------------------
三阶段一键完成
  点击「开始分析」→ 自动串联：
  统计预测 → 走势研判 → 命中率优化 → 在线学习 → AI 辅助解读。
  所有耗时操作后台线程执行，界面不卡顿。

多算法融合，权重诚实可冻结
  七算法（频率 0.68 / 监督学习 0.14 / 贝叶斯 0.10 /
  遗漏 0.06 / 趋势 0.01 / 马尔可夫 0.005 / 形态 0.003）
  + AI 解读，权重公开透明。
  经 walk-forward 回测验证，当前版本所有策略 95% CI
  落在随机基线区间内，系统将持续诚实披露。

全链路可观测，每期预测都可追溯
  MySQL 存储历史开奖（p5_history_data）、
  预测记录（p5_prediction_record）、
  AI 报告（p5_ai_report）、
  贝叶斯结果（p5_bayesian_result）、
  进化版本（p5_evolution_version），
  每列字段都有 docstring 注释。

开箱即用，降级优雅
  Python >= 3.9 + tkinter（无需额外 GUI 框架）
  MySQL >= 5.7 + Redis >= 6.0（可选：无 Redis 自动降级为本地缓存）
  安装依赖：pip install -r requirements.txt
  启动命令：python main.py
