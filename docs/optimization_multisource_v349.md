# 排列5 预测系统优化方案（v3.49）— 设计思路与重构要点

> 适用范围：GUI「开始分析」功能背后的算法 / 策略 / 逻辑 / 处理流程。
> 配套代码：`modules/ml_predictor.py`（新增）、`modules/predictor.py`（权重再平衡）、
> `scripts/backtest_multisource.py`（诚实回测）、`version.py` → v3.49。

---

## 0. 一句话结论（诚实优先）

排列5是**公平摇号、独立抽取**，每位数字 0-9 出现概率恒为 10%，**不存在稳定可超越随机基线的信号**。
本次优化的真实价值**不是**「魔法般提高命中率」，而是三点：

1. **真正利用**此前完全被浪费的丰富多源数据库表（用户明确要求）；
2. 以**无偏的监督模型**替代一个被实证为噪声、却占融合 34% 权重的「冷号」手工信号；
3. 建立**带 95% 置信区间的走窗回测**，纠正历史上「11% 显著超随机」的误导性结论。

走窗回测（2060 次独立试验）显示：新融合 Top-1 点估计 11.70%（CI 10.4–13.2%），
与随机基线（10%）、旧融合（10.53%）的置信区间**相互重叠** —— 即统计上**未超越随机**，
这与公平摇号的科学结论一致。

---

## 1. 根因诊断（基于实证，非推测）

### 1.1 最丰富的数据资产从未进入预测层
数据库里这些表真实、完整、长期积累，但 `predictor.py` 的 7 个算法**只读取 `p5_history_data`**：

| 表 | 行数 | 内容 | 预测层是否消费 |
|---|---|---|---|
| `p5_history_data` | 1031 | 五位置开奖数字 + 和值 | ✅ 唯一被消费 |
| `p5_wan/qian/bai/shi/ge_trend_data` | ~1048/张 | 各位独立走势：遗漏 / 冷热 / 连号 | ❌ 从未读取 |
| `p5_spjzs_data` | 530 | 升平降（SPJ）方向遗漏 `miss_spj_{位}` | ❌ 从未读取 |
| `p5_hzzst_data` | 530 | 和值 / 和尾遗漏 `miss_hezhiwei` | ❌ 从未读取 |

> 注：`database.py` 会写入这些表，但 `predictor.py` 没有读取通道 —— 典型「建了不用」。

### 1.2 「冷号回补」信号编码了赌徒谬误
`omission_regression`（旧权重 **0.34**，占融合约 39%）的核心公式是
`score(num) = exp(β·遗漏值)`，即**遗漏越大（越冷）赋予越高概率**。
对独立公平摇号而言，冷号下一期出现概率**并不更高** —— 这是教科书级的赌徒谬误。
旧注释还声称它「与频率互补的第二可靠信号」「v3.12 回测 T1=11% 显著超随机」，
但那是某一特定 80/150 期窗口的采样噪声被误读为信号。

### 1.3 实证：没有信号能超越随机（2060 次独立试验）
固定切分（前 618 期训练 / 后 412 期测试，每位置一次独立试验，共 2060 次），带 Wilson 95% CI：

| 策略 | Top-1 | Top-3 | Top-5 | 对照随机(10/30/50) |
|---|---|---|---|---|
| B. 频率（无偏） | 10.05% [8.8–11.4] | 29.37% | 48.45% | 落于噪声内 |
| C. 冷号遗漏（赌徒谬误） | **9.71%** [8.5–11.1] | 31.80% | 51.94% | Top-1 略低于频率 |
| D. GB 全特征（多源） | 10.63% [9.4–12.0] | 29.71% | 50.49% | 落于噪声内 |
| E. GB 仅频率特征 | 11.55% [10.2–13.0] | 31.21% | 51.26% | 落于噪声内 |
| F. 生产当前融合(0.54频+0.34冷+0.10贝叶斯) | 10.53% [9.3–11.9] | 30.10% | 48.93% | 落于噪声内 |
| **G. 新融合 v3.49**(0.68频+0.14监督ML+0.06冷+0.10贝叶斯) | **11.70%** [10.4–13.2] | 31.26% | 50.39% | 与随机/旧融合 CI 重叠 |

**结论**：所有策略 CI 相互重叠，无任何策略统计显著超越随机；冷号信号 Top-1 甚至略低于频率。

## 2. 所选方案

**多源监督学习 + 权重再平衡**，在保留既有七算法融合框架（稳定、契约不变）的前提下：

- **新增第 8 个算法 `ml_supervised`**：用 `GradientBoostingClassifier` 按位训练，
  消费历史 + 独立位走势 + 升平降 + 和值四类表，经验学习各位数字分布。
- **权重再平衡**：把被实证为噪声的冷号权重（0.34）大幅下调到 0.06，
  把理论最优的无偏频率权重上调到 0.68，并给新监督模型 0.14，贝叶斯 0.10 不变。

### 为什么选监督学习（而非继续堆手工统计特征）
- 多源表是**结构化表格数据**，梯度提升是最契合、最稳健的模型族之一；
- 它能**从数据中经验学习**，不注入任何方向性偏见（正好对症「冷号」的手工偏见）；
- GUI 运行环境（Anaconda）自带 `sklearn 1.6.1`，**零新增依赖**；
- 若环境无 sklearn / 无 DB，`ml_supervised` **自动跳过**，融合退化为原有信号，契约不变。

### 为什么不全盘重构
系统已有冻结的诚实基线与稳定的融合/返回契约（v3.38/v3.45 多次验证）。
推倒重来风险高、收益为零（因为根本不存在可榨取的「信号」）。
最小侵入式地「接上多源数据 + 去掉噪声权重」是工程上最负责任的选择。

## 3. 重构要点（具体改动）

### 3.1 新增 `modules/ml_predictor.py`
- `predict_next(sorted_data, target_issue)` 返回 `List[Dict[int, float]]`
  （长度 5，每位 {0..9: 概率} 且和为 1），与 predictor 算法输出格式**完全一致**。
- 特征工程（严格只用 `≤ i` 的可观测数据，防前视偏差）：
  - 多窗口频率(10/20/40/60)、多窗口遗漏(20/60)、末位属性、连号标志；
  - SPJ 方向计数（升/平/降）、和尾频率、均值和值；
  - **位走势表**：遗漏 / 冷热(one-hot) / 连号（来自 `p5_*_trend_data`）；
  - **升平降表**：`miss_spj_{位}`（来自 `p5_spjzs_data`）；
  - **和值表**：`miss_hezhiwei`（来自 `p5_hzzst_data`）。
- 训练：每个位置用 `[60, n-1)` 构造样本，标签为 `j+1` 期数字，单模型 `GradientBoosting`（150 棵 / 深度 3）。
- **懒加载 + 优雅降级**：sklearn 与 DB 连接均在方法内 `try` 导入/连接；
  缺失或样本不足（<120）返回 `None`，调用方跳过，绝不影响其它信号。
- `_connect_db` 自动将项目根加入 `sys.path`，避免 `config` 导入失败。

### 3.2 `modules/predictor.py` 改动
- `P5PredictorConfig.DEFAULT_CONFIG`：
  - `frequency_weighted.weight`：**0.54 → 0.68**
  - `omission_regression.weight`：**0.34 → 0.06**（注释明确标注「实证为噪声，赌徒谬误」）
  - 新增 `ml_supervised`（enabled, weight **0.14**）
- `predict()`：新增 `self._ml_target_issue`，供监督模型定位被预测期号。
- `_run_algorithms()`：新增 `ml_supervised` 分支 —— 懒加载 `modules.ml_predictor.predict_next`，
  返回非 `None` 才并入 `results`；异常被捕获并降级，不阻断主流程。
- 融合逻辑（`_fuse_probabilities`）**未改动**，仍为加权平均，返回契约不变。

### 3.3 新增 `scripts/backtest_multisource.py`
- 从真实 DB 加载数据，走窗（train/test 切分 + 可选扩展窗口重训）评估；
- 输出各策略 Top-1/3/5 命中率 + Wilson 95% CI，并对照随机基线；
- 复现「生产当前融合」与「新融合」以便量化对比。
- ⚠️ 运行须知：本机 `import sklearn` 会被**沙箱拦截导致进程静默被杀**，
  必须 `dangerouslyDisableSandbox: true`（或直接在 Anaconda 终端）运行。

## 4. 诚实评估与边界

- **命中率口径**：Top-1 ≈ 10%、Top-3 ≈ 30%、Top-5 ≈ 50%（每位独立随机基线）。
- **本次优化未声称突破随机**：新融合点估计略高，但 95% CI 与随机/旧融合重叠。
- **真实收益**：① 多源表真正被利用；② 去掉一个被实证为噪声的高权重偏见信号；
  ③ 用带置信区间的走窗回测替代「挑窗口说超随机」的旧做法，结论可复现、可辩护。
- **不应承诺**：任何「稳赚」「提高中奖概率」的表述。系统应继续如实标注
  「排列5为公平摇号，无法稳定超越随机基线」。
