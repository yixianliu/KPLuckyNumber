## 文章摘要（100字内）
本文介绍一款开源桌面端排列5数据分析系统（Python + Tkinter），聚焦解决"数据收集难、分析不可复现、预测无法验证、AI解读落不了地、环境依赖重"五大痛点。系统实现七算法融合预测（权重透明可冻结）、全链路入库追溯、自我进化自动重训、三级智能缓存秒级响应，**诚实声明：不承诺超越随机基线，真实价值在于数据整合能力、分析透明度与结果可解释性**。

## 正文大纲

### 一、项目背景：为什么要造这个轮子？
- 排列5开奖数据分散在多个官网/第三方站点，手工复制粘贴到Excel极其低效且易错
- 网上预测代码多为单算法脚本，口径不一、无法横向对比、更无法复现
- 多数工具"只管算、不管验"，预测完不知道准不准，长期效果全凭感觉
- 直接调用大模型做解读，返回格式混乱、JSON解析失败、推理链条丢失
- 很多开源项目强依赖 Redis、特定版本库，环境一缺就跑不起来

### 二、核心功能：一张图看懂完整闭环
```
数据采集(多源爬虫) → 统计预测(七算法融合) → 走势研判(40期周期) 
    → 命中率优化(自动验证) → 在线学习(逐算法归因) → AI辅助解读(JSON修复+入库)
```
- **数据爬取**：增量/全量一键抓取，自动去重、补全缺失期号，入库 MySQL
- **智能分析中心**：一键"开始分析"，六阶段流水线全自动跑通，后台线程不卡界面
- **智能分析与验证**：预测验证、命中率报告、历史回测、特征分析工具集
- **自我进化**：后台守护线程监控数据量，达阈值自动触发 walk-forward 无偏重训，未超越基线不入线上

### 三、五大痛点的解决方案（干货核心）

| 痛点 | 传统做法 | 本系统方案 | 关键技术点 |
|------|----------|------------|------------|
| 数据源分散 | 手工复制粘贴 | 多源爬虫+自动入库 | requests+BS4、增量抓取、去重补全 |
| 算法不可比 | 东拼西凑脚本 | 统一融合框架 | 七算法加权、权重冻结、lookback=60 |
| 预测无验证 | 事后诸葛亮 | 每期自动验证+命中率统计 | 在线学习引擎、逐算法归因、滚动回测 |
| AI解读不可控 | 直接喂Prompt | JSON修复+逐算法归因列 | 结构化输出、推理链入库、事后可查 |
| 环境脆弱 | 缺啥崩啥 | 惰性加载+优雅降级 | Lazy Import、Redis缺失降级本地、可选组件解耦 |

### 四、五大独特价值（差异化竞争力）

1. **多算法融合，权重透明不藏私**  
   频率(0.68)/监督学习(0.14)/贝叶斯(0.10)/遗漏(0.06)/趋势(0.01)/马尔可夫(0.005)/形态(0.003) 八维权重公开可查、可冻结，核心逻辑不进黑箱。

2. **全链路可追溯**  
   5张核心表全入库：`p5_history_data`(历史开奖)、`p5_prediction_record`(预测记录)、`p5_ai_report`(AI报告)、`p5_bayesian_result`(贝叶斯)、`p5_evolution_version`(进化版本)，关键字段均有注释，任意一次分析可回溯到原始数据与算法依据。

3. **诚实边界，不忽悠用户**  
   系统显性声明：排列5为公平摇号，无法稳定超越随机基线（Top-1≈10%、Top-3≈30%、Top-5≈50%）。所有策略效果带置信区间，**绝不把噪声包装成"稳赚信号"**。

4. **自我进化引擎（自动重训+无偏评估）**  
   新数据积累达阈值 → 自动触发重训 → walk-forward样本外评估 → 候选方案超越历史基线才入线上，否则归档为试验。**绝不擅自改动线上融合权重**。

5. **响应快，不卡界面**  
   三级智能缓存：LFU长期缓存(热点数据) + LRU短期缓存(最近查询) + AI响应缓存(大模型调用)，重复分析秒级返回；耗时任务全部后台线程执行，GUI主线程零阻塞。

### 五、技术架构亮点（适合技术同行参考）
- **模块化架构**：24个核心模块，数据层/统计层/模型层/生成层/展示层分离
- **懒加载机制**：`_LazyClass` 延迟绑定重模块，启动快、内存占用低
- **三向引用扫描**：删除模块前必做 静态import / 动态import_module / `_LazyClass`字符串 三向扫描，杜绝误删运行时依赖
- **AST级Docstring覆盖**：694函数/27类 100%中文文档字符串覆盖，幂等注入、装饰器感知
- **数据库自治**：自动建库建表、自动重连、泛型读写工具类

### 六、诚实基线数据（拒绝营销号）
