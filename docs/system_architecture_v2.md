### 1.2 核心算法说明

#### 1.2.1 五大预测算法

| 算法 | 权重 | 原理 | 优点 | 缺点 |
|------|------|------|------|------|
| 频率加权 | 35% | 统计历史出现频率，拉普拉斯平滑 | 简单有效，捕捉长期规律 | 无法捕捉短期趋势 |
| 遗漏回归 | 25% | 遗漏值越大，回归概率越高（指数模型） | 利用回归原理 | 忽略实际数据周期 |
| 趋势动量 | 15% | 线性回归预测趋势方向 | 捕捉短期趋势 | 噪声敏感 |
| 马尔可夫 | 15% | 基于上一期号码的状态转移 | 考虑状态依赖 | 容易过拟合 |
| 形态延续 | 10% | 奇偶/大小/质合形态延续分析 | 识别模式规律 | 数据量不足时不稳定 |

#### 1.2.2 AI融合策略

```
最终概率 = 0.9 × 统计模型概率 + 0.1 × AI推荐概率

AI权重仅10%，因为：
• AI不产生新信息，只是统计规律的再包装
• 避免AI极端推荐主导最终结果
• 保持统计模型的基础作用
```

#### 1.2.3 组合生成策略

```
1. 对每个位置取Top-3概率最高的号码
2. 生成笛卡尔积（3^5 = 243种组合）
3. 按概率乘积排序
4. 取Top-10作为推荐组合
```

### 1.3 当前存在的问题

| 问题类别 | 具体表现 | 影响程度 |
|----------|---------|---------|
| **特征缺失** | 缺乏季节性、周期性特征 | 中 |
| **硬编码权重** | 算法权重固定，无法自适应 | 高 |
| **无反馈闭环** | 预测结果不反哺模型 | 高 |
| **Redis规范缺失** | Key命名混乱，无TTL管理 | 中 |
| **专家数据浅层利用** | 仅提取号码，未量化专家信誉 | 中 |
| **无反例学习** | 未命中原因未分析 | 高 |

### 2.4 预测命中率优化策略

#### 2.4.1 特征权重动态调整

```python
# 基于近期表现的权重调整规则
if 近10期命中率 < 期望值:
    增加趋势动量权重(-0.03)
    增加形态延续权重(+0.03)
elif 近10期命中率 > 期望值:
    增强频率加权权重(+0.05)
    增强遗漏回归权重(+0.05)

# 相邻位约束惩罚
if 相邻位置推荐号码重叠度 > 60%:
    降低重叠号码概率(×0.85)

# 和值范围约束
if 和值 < 10 或 和值 > 35:
    降低组合评分(×0.5)

# 奇偶比约束
if 全奇 或 全偶:
    大幅降低评分(×0.3)
```

#### 2.4.2 软约束融合

```python
# 专家信誉加权
融合_奇偶倾向 = Σ(专家_奇偶倾向 × 专家信誉分数)

# 共识号码优先
if 多≥2位专家推荐同一号码:
    提升该号码基础概率(×1.1)

# 分歧位置降权
if 某位置推荐号码>5个:
    降低该位置权重(×0.9)
```

### 2.5 在线学习机制

#### 2.5.1 自动验证流程

```
开奖时间 → 触发自动验证
          ↓
读取预测记录 (p5_prediction_record)
读取实际结果 (p5_history_data)
          ↓
计算命中指标:
  • 完全命中数
  • 部分命中数  
  • 各位置命中率
  • 置信度准确度
          ↓
更新命中率统计表 (p5_performance_stats)
          ↓
反例记录 → 分析失败模式
          ↓
模型权重增量更新 → 保存新版本
```

#### 2.5.2 反例学习

```python
# 记录未命中模式的共同特征
反例记录 = {
    "missed_position_numbers": [
        {"position": 2, "actual": 7, "predicted_prob": 0.05}
    ],
    "feature_patterns": {
        "low_confidence_majority": True,  # 多数预测概率低
        "random_outlier": False
    }
}

# 基于反例调整策略
if low_confidence_majority:
    降低特征工程权重 (+0.02 to frequency/omission)
if random_outlier:
    增加趋势动量波动容忍度 (+0.01)
```
