# 项目系统性梳理与BUG检测总结

## 项目架构概览

**KPLuckyNumber** 是一个排列5 AI智能分析系统（v3.60），采用模块化GUI架构：

```
项目结构:
├── main.py              # GUI入口（Tkinter）
├── config.py            # 全局配置源
├── version.py           # 版本信息（单一事实源）
├── modules/             # 核心业务模块（24个）
│   ├── pipeline.py      # ★ 预测流水线（两步式）
│   ├── predictor.py     # 七算法融合引擎
│   ├── database.py      # MySQL封装
│   ├── self_evolution.py # 自我进化引擎
│   ├── ml_predictor.py  # 监督学习
│   └── ...
├── tests/               # 单元测试
├── scripts/             # 工具脚本
└── data/                # 数据资产
```

## 核心业务流程

### 「开始分析」六阶段流水线
1. 统计预测（七算法融合）
2. 走势引擎（近60期分析）
3. 快速预测（复用概率）
4. 命中率优化
5. 在线学习闭环
6. AI辅助解读

### 自我进化后台流程
```
collect → baseline → evolve → evaluate → persist → done
```

| 层级 | 技术 |
