> 诚实声明：本系统不承诺、也无法超越随机中奖基线；真实价值在于数据整合、分析透明度、结果可解释性与响应性能。

---

## 📌 一句话介绍

**排列5 AI 智能分析系统** 是一套桌面图形界面（GUI）软件，把零散的排列5历史开奖数据，整理成结构化、可追溯、可解释的分析结果。它覆盖"数据采集 → 多算法融合分析 → 走势研判 → 命中率验证 → 在线学习"的完整闭环，并配有人工智能辅助解读。

---

## 🎯 它解决了哪些实际问题

| 实际问题 | 本软件的做法 |
|----------|--------------|
| **数据收集靠手工** | 内置多源数据爬虫，增量 / 全量一键抓取，结果自动写入数据库，告别复制粘贴 Excel |
| **分析结果不可复现** | 统一融合框架，同一份输入得到可复现、可横向对比的分析结果 |
| **预测完不知对错** | 每期开奖后自动验证、统计命中率、记录历史，长期效果看得见 |
| **AI 解读落不了地** | JSON 修复 + 逐算法归因，AI 解读稳定解析、入库、可回溯 |
| **环境缺组件就跑不起来** | 惰性加载 + 优雅降级，缺 Redis / 缺可选库也能启动主界面 |

---

## 😤 核心痛点与解决方案

- **痛点 1 · 数据源分散，手工整理低效**
  → 多源爬虫 + 自动入库，一键获取，数据集中管理。
- **痛点 2 · 算法脚本满天飞，无法对比**
  → 七算法 + 监督学习混合融合，权重透明、同一输入可复现。
- **痛点 3 · 预测完不知道对错**
  → 在线学习 + 滚动回测 + 命中率统计，每期自动验证闭环。
- **痛点 4 · AI 输出不可控，黑箱难解释**
  → JSON 修复 + 逐算法归因列，每期预测都有完整推理链可追溯。
- **痛点 5 · 复杂项目跑不起来**
  → 惰性加载（Lazy Import）+ 优雅降级，缺 Redis 也能跑。

## ✨ 独特价值

1. **多算法融合，权重透明不藏私**
   频率 / 监督学习 / 贝叶斯 / 遗漏 / 趋势 / 马尔可夫 / 形态 七类算法统一融合，权重公开可查、可冻结，核心逻辑不进黑箱。

2. **全链路可追溯**
   历史开奖（`p5_history_data`）、预测记录（`p5_prediction_record`）、AI 报告（`p5_ai_report`）、贝叶斯结果（`p5_bayesian_result`）、进化版本（`p5_evolution_version`）全部入库，关键字段均有注释。

3. **诚实边界，不忽悠用户**
   系统明确声明：排列5 为公平摇号，无法稳定超越随机基线；所有策略效果都带置信区间诚实披露。

4. **自我进化引擎（自动重训 + 无偏评估）**
   新数据积累到阈值后自动触发重训，走窗（walk-forward）样本外评估；候选方案未超越历史基线则归档为试验，绝不擅自改动线上融合权重。

5. **响应快，不卡界面**
   三级智能缓存（长期 / 短期 / AI 响应）让重复分析秒级返回，耗时任务全部后台线程执行。

## 🧩 主要功能

- **数据爬取**：多源增量 / 全量抓取排列5历史开奖数据，自动入库。
- **智能分析中心**：一键"开始分析"，串联统计预测 → 走势研判 → 命中率优化 → 在线学习 → AI 辅助解读。
- **智能分析与验证**：预测验证、命中率报告、历史回测、特征分析等工具集。
- **自我进化**：后台自动重训与版本管理，过程可观测、可回滚。
- **结果导出**：分析结论、日志、报告可一键复制 / 导出。
