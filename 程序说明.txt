排列5 AI 智能分析系统 — 程序说明
================================================================

软件名称：排列5 AI 智能分析系统
当前版本：v3.59（版本号由程序内置 version.py 统一维护）
适用彩种：排列5（体彩，每日开奖的数字型彩票）
运行方式：桌面图形界面（GUI），双击 main.py 即可使用


----------------------------------------------------------------
一、这个软件是做什么的
----------------------------------------------------------------

排列5 AI 智能分析系统，是一套面向"排列5历史数据分析"的
桌面软件。它把"数据采集 → 多算法融合分析 → 走势研判 →
命中率验证 → 在线学习"做成了完整闭环，并配有人工智能（AI）
辅助解读。

一句话概括：它帮您把散乱的排列5历史开奖数据，整理成结构
化、可追溯、可解释的分析结果，让您看得清"数据里发生了什么"，
而不是凭感觉选号。

需要特别说明的是：排列5 是公平摇号、独立抽取，本软件
不承诺、也无法稳定超越随机中奖概率。它的真实价值在于
"数据整合能力、分析透明度、结果可解释性、响应性能"，
而不是"保证中奖"。这一点在后面的"诚实声明"中会再次强调。


----------------------------------------------------------------
二、它能帮你解决哪些实际问题
----------------------------------------------------------------

1. 数据收集不再靠手工
   开奖数据分散在多个网站，过去只能复制粘贴到 Excel，
   既耗时又容易出错。本软件内置多源数据爬虫，支持增量 /
   全量一键抓取，结果自动写入本地数据库，省去重复劳动。

2. 分析结果可复现、可对比
   网上能找到大量"单算法"预测代码，但东拼西凑、口径不一。
   本软件用统一的融合框架跑多种算法，同一份输入能得到
   可复现的分析结果，方便您横向对比不同思路。

3. 预测得准不准，自己能验证
   很多工具只管"算出来"，不管"算得对不对"。本软件每期
   开奖后自动验证命中情况、统计命中率、记录历史，让您
   清楚知道自己的分析长期处在什么水平。

4. AI 解读"看得懂、留得下"
   直接调大模型常常拿到格式乱、落不了库的回答。本软件
   内置 JSON 修复与逐算法归因，AI 给出的解读能稳定解析、
   入库，并保留完整的推理链条，事后可查。

5. 环境缺这少那也能跑起来
   很多项目一缺 Redis、一缺某个库就整体崩溃。本软件采用
   惰性加载与优雅降级：缺少 Redis 时自动退回本地缓存，
   缺少可选组件时主界面照常启动，降低"跑不起来"的门槛。


----------------------------------------------------------------
三、它带来的独特价值
----------------------------------------------------------------

★ 多算法融合，权重透明不藏私
   七类算法（频率 / 监督学习 / 贝叶斯 / 遗漏 / 趋势 /
   马尔可夫 / 形态）统一融合，各项权重公开可查、可冻结，
   不把核心逻辑塞进黑箱。

★ 全链路可追溯
   历史开奖、预测记录、AI 报告、贝叶斯结果、进化版本等
   全部入库，关键字段均有注释，任何一次分析都能回溯到
   原始数据与算法依据。

★ 诚实边界，不忽悠用户
   系统明确声明：排列5 为公平摇号，无法稳定超越随机基线。
   所有策略效果都带置信区间诚实披露，绝不把噪声包装成
   "稳赚信号"。

★ 自我进化引擎（自动重训 + 无偏评估）
   新数据积累到一定量后自动触发重训，并用走窗（walk-
   forward）方式做样本外评估；若候选方案未超越历史基线，
   一律归档为试验，绝不擅自改动线上融合权重。

★ 响应快，不卡界面
   三级智能缓存（长期 / 短期 / AI 响应）让重复分析秒级
   返回，耗时任务全部在后台线程执行，界面流畅不卡顿。


----------------------------------------------------------------
四、它解决了哪些核心痛点
----------------------------------------------------------------

痛点 1：数据源分散，手工整理低效
   → 多源爬虫 + 自动入库，一键获取，告别复制粘贴。

痛点 2：算法脚本满天飞，无法对比
   → 统一融合框架，同一输入可复现、可横向对比。

痛点 3：预测完不知道对错
   → 在线学习 + 滚动回测 + 命中率统计，每期自动验证。

痛点 4：AI 输出不可控，黑箱难解释
   → JSON 修复 + 逐算法归因，每期预测都有可查的推理链。

痛点 5：复杂项目跑不起来
   → 惰性加载 + 优雅降级，缺 Redis / 缺可选库也能启动。


----------------------------------------------------------------
五、主要功能一览
----------------------------------------------------------------

• 数据爬取：多源增量 / 全量抓取排列5历史开奖数据。
• 智能分析中心：一键"开始分析"，串联统计预测、走势研判、
  命中率优化、在线学习、AI 辅助解读六个阶段。
• 智能分析与验证：预测验证、命中率报告、历史回测、
  特征分析等工具集。
• 自我进化：后台自动重训与版本管理，过程可观测、可回滚。
• 结果导出：分析结论、日志、报告可一键复制 / 导出。


----------------------------------------------------------------
六、快速使用流程
----------------------------------------------------------------

1. 准备环境：安装 Python（≥ 3.9）与依赖
   （pip install -r requirements.txt），并配置好
   config.py 中的数据库连接。
2. 启动软件：运行 python main.py，进入主界面。
3. 采集数据：在"数据爬取"中执行一次增量 / 全量抓取。
4. 开始分析：进入"智能分析中心"，点击"开始分析"，
   等待后台流水线完成。
5. 查看结果：在结果面板查看预测号码、走势研判与 AI 解读；
   在"智能分析与验证"中查看命中率与回测结论。

（详细安装、配置与依赖说明，请参见随附的 README.md。）
